# Pac-Man Game

一个基于 Python pygame 的吃豆人游戏。

## 功能

- 开始画面（动态 Pac-Man logo + 幽灵展示 + 闪烁提示）
- 方向键 / WASD 操控，P / ESC 暂停
- 4 个差异化幽灵 AI（Blinky 直追 / Pinky 堵路 / Inky 侧翼 / Clyde 远追近逃）
- 多关卡系统：通关后难度递增（幽灵加速、能量豆效果缩短）
- 水果道具系统：随关卡升级（樱桃 100 → 西瓜 1000）
- 连击计分：连续吃幽灵 200 → 400 → 800 → 1600
- 分数弹出文字动画
- 程序化音效（无需外部文件）
- 大力丸脉冲闪烁动画
- 死亡动画 + READY! 倒计时
- 窗口自动居中

## 运行

```bash
pip install pygame
python pacman-game.py
```
